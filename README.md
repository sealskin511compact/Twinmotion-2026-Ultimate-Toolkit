## Frequently Asked Questions

**Q: Is this toolkit compatible with older versions of Twinmotion, like 2025 or 2023?**
A: No, this toolkit is specifically developed and tested for **Twinmotion 2026**. Using it with other versions may lead to instability or missing features. We recommend checking for updates if you plan to upgrade Twinmotion.

**Q: I'm experiencing a performance drop when the toolkit overlay is active. What can I do?**
A: You can disable the performance monitor overlay from the toolkit's settings menu under the "View" tab. It is designed to be lightweight, but performance can vary based on system specifications and the complexity of the scene being rendered in Twinmotion.

**Q: Can the toolkit's plugin manager install plugins from any source?**
A: The plugin manager is designed to handle plugins that are properly packaged for Twinmotion. It provides a safe way to install and manage community and official extensions. Always ensure you trust the source of any third-party plugin you install.

**Q: Does the toolkit require an active internet connection to function?**
A: An internet connection is required for initial installation, downloading plugin updates, and accessing the online asset library preview. Once installed, core features like render presets and the local asset library work offline.
